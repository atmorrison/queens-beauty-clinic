# Queens Beauty Clinic
A minimal website for Queens Beauty Clinic that showcases the business, allows customers to book appointments using Microsoft Bookings, and provides a secure payment portal using Verifone (Eftpos New Zealand).

# Technology stack
- Frontend: HTML + TypeScript w/ Vite bundling
- Backend: .NET Azure Functions w/ cold start optimisations (e.g., ReadyToRun) 

# Features

## Landing page
The website tells customers what Queens Beauty Clinic is, and provides clear details about the services provided, as well as ways to get in touch with the business.

## Bookings
The website links to a booking portal hosted on Microsoft Bookings, allowing customers to book and manage their appointments online.

## Payment portal
The website can generate links to the Verifone Hosted Checkout using an Azure Function to allow users to pay for their appointment online.
